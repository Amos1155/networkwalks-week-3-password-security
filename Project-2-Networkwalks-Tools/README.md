# Project 2: Password Recovery with Networkwalks Tools

## Overview
This lab focused on password recovery using two online tools provided by Networkwalks: Hash Calculator and Password Cracker.

## Tools Used
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Windows OS
- Web Browser

## Objectives
- Understand how password hashes are extracted from protected PDF files.
- Explore password recovery using online security tools.
- Understand how weak passwords can be vulnerable to password-cracking attempts.

## Practical Work
I started by uploading the protected PDF to the Networkwalks Hash Calculator to extract its hash.

I then copied the extracted hash into the Networkwalks Password Cracker and allowed the tool to perform the recovery process.

After obtaining the password, I tested it by opening the protected PDF.

## Outcome
Successfully completed the exercise and verified the recovered password by opening the protected PDF.

## Evidence
- Hash Calculator result.
- Password Cracker result.
- Protected PDF successfully opened.

## Key Learning
This exercise helped reinforce my understanding of password hashes, password recovery, and the importance of using strong passwords to protect sensitive files.

*All activities were performed as part of an authorised cybersecurity training lab.*
