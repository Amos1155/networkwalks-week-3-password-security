# Project 1: Password Recovery with John the Ripper

## Overview
This lab focused on understanding password security and recovering the password of a protected PDF file using John the Ripper (JTR) and Johnny GUI.

## Tools Used
- John the Ripper
- Johnny GUI
- Windows OS

## Objectives
- Understand how password hashes are extracted from protected PDF files.
- Explore password recovery using John the Ripper.
- Understand the importance of strong passwords and secure file protection.

## Practical Work
I used John the Ripper and its graphical interface, Johnny, to work through the password recovery exercise.

The lab involved extracting the PDF hash, preparing it for analysis, running the recovery process, and verifying the recovered password by opening the protected PDF.

## Outcome
Successfully completed the password recovery exercise and opened the protected PDF using the recovered password.

## Evidence
- Successful password recovery screenshot.
- Protected PDF successfully opened.

## Key Learning
This exercise improved my understanding of password hashes, password recovery techniques, and the risks associated with weak passwords.

*All activities were performed as part of an authorised cybersecurity training lab.*
