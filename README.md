# Week 3 Cybersecurity Projects – Password Security

## Overview

As part of my Week 3 cybersecurity practical training with Networkwalks, I completed two hands-on exercises focused on password security and password recovery.

The exercises gave me an opportunity to work with different tools and understand how password hashes are extracted and used in password recovery.

## Projects Completed

### Project 1: Password Recovery with John the Ripper

**Tools:** John the Ripper (JTR), Johnny GUI, Windows.

Worked with John the Ripper and its graphical interface, Johnny, to recover the password of a protected PDF file.

**Outcome:** Successfully recovered the password and opened the protected PDF.

[View Project 1](Project-1-John-the-Ripper/README.md)

### Project 2: Password Recovery with Networkwalks Tools

**Tools:** Networkwalks Hash Calculator, Networkwalks Password Cracker.

Used the Hash Calculator to extract the hash from a protected PDF and the Password Cracker to recover its password.

**Outcome:** Successfully recovered the password and verified it by opening the protected PDF.

[View Project 2](Project-2-Networkwalks-Tools/README.md)

## Key Skills Practised

- Password security fundamentals
- Password hash extraction
- John the Ripper
- Johnny GUI
- Password recovery concepts
- Understanding dictionary-based attacks
- Practical security testing

## Key Takeaway

One major lesson from these exercises is that password security goes beyond simply setting a password. Understanding how passwords can be tested and recovered highlights the importance of using strong, unique passwords to protect sensitive information.
